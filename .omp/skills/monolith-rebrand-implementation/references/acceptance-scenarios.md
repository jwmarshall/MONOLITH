## Completion report shape

- Outcome: exact marker and mode (selected presentation, codebase-only rename or full cutover), targets and affected routes/states.
- Changed paths and complete caller/owner cutover; obsolete scoped paths removed.
- Presentation replaced / behavior preserved; M01–M12 applicability and findings.
- Source review: native exact names or explicitly labelled portable fallback, scope, actual findings and unresolved blockers.
- Runtime: environment, synthetic fixture identity, actual route/state/viewport/mode, steps/results, safe artifact paths; source-only versus measured facts separated. Codebase-only changes state why browser rows are not applicable and report relevant caller/configuration/command and synthetic behavior evidence instead.
- Checks: exact inspected commands actually run and outcomes, failures, unrun gates and why. A worker names integration-owner checks without claiming to run them.
- Docs: existing contracts updated to actual migration; untouched legacy scope intentionally unchanged.
- Remaining limitations: precise prerequisite or conflicting decision; no silent partial completion and no rolling status file.
